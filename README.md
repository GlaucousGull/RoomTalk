oomTalk
Python全栈 + WebRTC 一对一音视频通话项目

## 项目介绍
RoomTalk 是基于 **Python全栈 + WebSocket + WebRTC** 开发的实时通讯系统，分为登录、聊天两大界面，实现账号登录、公私域房间管理、在线文字聊天、一对一P2P音视频四大核心能力。
用户创建公/私域房间后，同房间用户可即时文字互动，还能通过WebRTC建立点对点音视频通话。
项目全量部署阿里云ECS，配置独立域名与SSL证书，全站HTTPS/WSS加密。
> ⚠️ 注意：前端仅适配PC端浏览器，手机/平板无页面兼容，无法正常访问；音视频通话仅支持一对一P2P，暂不支持多人通话。

## 技术栈
- 后端：Python（WebSocket信令服务）
- 前端：原生HTML+CSS+JavaScript
- 实时通讯：WebSocket（文字信令）+ WebRTC（P2P音视频）
- 部署：阿里云ECS + Nginx反向代理
- 安全：Let's Encrypt SSL证书，全站HTTPS/WSS加密

## 界面与四大核心功能
### 两大系统界面
1. **登录界面**：项目访问首页面，用户在此完成账号登录，登录后生成全局唯一UID作为身份标识，是进入聊天系统的必经页面。
2. **主聊天界面**（项目操作主面板，参考项目截图）
    - 左侧：用户UID信息、创建房间/刷新房间按钮、全平台房间列表（区分公域/私域）
    - 右侧：选中房间的聊天面板、底部消息输入框、右上角视频通话发起按钮，顶部展示房间名与实时在线人数。

### 四大功能
1. **账号登录**：登录页校验用户身份，登录生成独立UID，用于聊天、呼叫身份标记；
2. **公私域房间创建**：左侧【创建房间】支持两类房间：
   - 公域房间：公开展示在房间列表，所有用户可自由加入；
   - 私域房间：加密私密房间，不在公共列表展示，凭房间号准入；
   搭配【刷新房间】，实时拉取平台最新房间数据。
3. **实时文字聊天**：双方进入同一房间，底部输入消息发送，全房间在线用户即时接收文字消息。
4. **WebRTC一对一音视频**：同房间存在2名在线用户，右上角点击【发起视频通话】，信令自动协商，建立P2P点对点音视频链路，仅支持双人通话。

## 使用流程
1. 打开在线站点，在登录界面完成账号登录；
2. 进入聊天页，左侧创建公域/私域房间；
3. 分享房间号，邀请好友进入相同房间；
4. 底部输入内容发送，实现文字聊天；
5. 点击右上角【发起视频通话】，建立一对一P2P音视频。
